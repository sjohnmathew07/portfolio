Case Study 01 • Physics & Game Mechanics
Browser Game Engine

Interactive Archery Game — Browser-Based Physics Simulation

A high-precision browser archery game built without heavy external canvas libraries, utilizing clean JavaScript event handling, real-time projectile physics, and responsive DOM manipulation to deliver engaging interactive gameplay.

The Architectural Challenge

Creating responsive, tactile games in the DOM requires managing smooth arrow velocity vectors, tracking multi-axis user aiming, rendering dynamic moving targets, and calculating frame-by-frame hit-box intersections while keeping CPU consumption low across desktop and mobile browsers.

The Engineering Solution

Engineered an event-driven aiming loop that maps pointer input to an angle and impulse power vector. Programmed dynamic target oscillation routines with pseudo-random speed offsets. When the arrow is released, an animation loop computes projectile coordinates, executes real-time collision boundaries, increments progressive scoring streaks, and triggers visual feedback without DOM layout thrashing.

Case Study 02 • 3D CSS Coordinate Geometry
Spatial UI & Transformations

3D Cube Twist — Interactive Multi-Axis CSS Spatial Engine

An interactive 3D Cube visualization crafted using pure CSS 3D transformations and JavaScript event orchestration, creating realistic geometric depth, facet lighting, and smooth rotational momentum directly within the browser viewport.

The Architectural Challenge

Most 3D web visualizations rely on heavy WebGL libraries like Three.js. The goal here was to push the native capabilities of modern CSS 3D coordinate geometry to its absolute limits — maintaining 60fps rotational stability, realistic orthogonal face orientation, and responsive touch gestures using pure CSS and lightweight vanilla JavaScript.

The Engineering Solution

Structured an orthogonal six-faced cube using transform-style: preserve-3d, calculated perspective depths via translateZ offsets, and bound interactive drag and button listeners to update rotateX and rotateY angles. Implemented momentum smoothing and face-shading rules to produce an organic, physical feel for users interacting with each facet.

Case Study 03 • Basic Electrical & Electronics Engineering
Hardware & Multi-Sensor Automation

Smart Home Automation System — Multi-Sensor Environmental Safety Circuit

A physical hardware-integrated smart automation prototype integrating real-time fire detection, conductive rain moisture sensing, and an LDR-driven automatic street-lighting system to deliver proactive environmental safety and autonomous circuit control.

The Architectural Challenge

Residential automation setups often treat safety alarms and energy management as separate, costly silos. The engineering objective was to design a unified electrical prototype that concurrently monitors multiple analog and digital sensory signals — optical fire wavelengths, conductive precipitation, and ambient illumination — and reliably triggers autonomous relay interventions.

The Engineering Solution

As part of the BEEE course curriculum, I engineered a circuit prototype combining optical flame sensors, a conductive rain grid, and Light Dependent Resistors (LDR). Designed voltage-divider networks to calibrate analog thresholds. When ambient light diminishes, the circuit autonomously illuminates lighting loads. When precipitation is detected, protective shutters or alert indicators fire. When thermal or flame signatures cross safety limits, an emergency alert cycle engages to decouple vulnerable loads.
